# M3 キーフレーム仕様（実装済み）

## モデル

- `Interpolation`: `hold / linear / smooth / bezier{x1,y1,x2,y2}`。
  Bezier は開始キー側セグメントの cubic-bezier（CSS 式、二分法 12 回）。
- `loops`（パラメータ単位）：`off / loop / pingpong`。範囲外を写像。
- 評価は Rust＝TS 同一アルゴリズム（`eval.test.ts` で一致確認）。
- **基本値フォールバック**：キーなし→`params` の基本値→既定値。
  （M2 の全面白バグの反省。回帰テストあり）

## Inspector

- 種別ごとのスキーマ行（数値スライダ/整数/色/本文）。
- ◆：キーなし→再生ヘッドに打鍵、キーあり→その値を編集、
  ◆発光＝現フレームにキー。クリックで削除。
- 値編集はキーありなら打鍵、なければ基本値更新。

## スプライン（Graph タブ）

- 左ツリー：表示切替＋ループ選択、プリセット 7 種＋複写/貼付。
- 右 SVG：カーブ・キー◆ドラッグ（時間＋値）・Bezier ハンドル。
- 数値系のみ描画。貼付は相対オフセット維持。

## レンダー連携

- `render-core` は全パラメータをフレーム評価（x/y/opacity/明度/…）。
- プレビュー再生中もアニメが反映される。

## 制限（M4 以降）

- 回転、グラフのズーム、色・テキストのカーブ表示は未対応。
- キー補間のプロジェクト間コピペは未対応。
