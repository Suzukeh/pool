# ADR-002: プラグインは別プロセス実行、言語自由

- 状態：採用
- 日付：2026-09-14

## 背景

AviUtl2 の `.auf2/.mod2` はインプロセス DLL のため、
1 プラグインの暴走が本体を道連れにし、D3D11 に縛られる。
Slang で書きたい上級者と、手軽さ優先の層を両立したい。

## 決定

- 本体標準エフェクトは WGSL をインプロセス実行（高速・安全）。
- 外部プラグインは **別プロセス**（`plugin-host`）で実行し、言語自由
  （Slang / HLSL / CUDA / Python+Torch 等）。
- 契約はフレーム規格のみ：RGBA16F + メタデータ。
- 受渡しは共有メモリのゼロコピー
  （Win: DXGI shared / Mac: IOSurface / Linux: DMA-BUF）。
- 配布は zip + マニフェストの D&D インストール（au2pkg 相当）。

## 帰結

- クラッシュ隔離：プラグイン kill でも本体は生存。
- 権限分離・将来のマーケット審査の土台になる。
- 代償は IPC 実装コスト（M4）とフレーム転送の設計。
